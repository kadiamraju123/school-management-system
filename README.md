# School Management Mini System

## 📌 Description
This is a full stack web application that allows an admin to manage students and assign tasks.

---

## 🚀 Features
- Admin login authentication
- Add, edit, delete students (CRUD)
- View student list
- Assign tasks to students
- Mark tasks as completed
- View all tasks

---

## 🛠 Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
